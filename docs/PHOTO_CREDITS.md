## Aircraft photos

Aircraft photos are fetched at runtime from the free
[Planespotters.net photo API](https://www.planespotters.net/photo/api) (registration
first, ICAO24 hex fallback) and shown with the photographer's name linked to the
original photo page, as the API terms require.

## Ship photos

Ship photographs are courtesy of [VesselFinder](https://www.vesselfinder.com),
fetched per-MMSI via the backend proxy (see `backend/src/routes/ship-photo.ts`).
